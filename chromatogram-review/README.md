# 色谱曲线复核工具

纯本地运行的色谱曲线复核工具：无服务端，原始数据与方法保存在浏览器 IndexedDB 中。

## 功能

- **CSV 导入**：自动识别逗号/分号/制表符/空白分隔与表头，自动匹配时间、响应列；多列数值文件可手动选列。导入后原始曲线立即可见，且始终显示。
- **可选平滑辅助曲线**：Savitzky-Golay 平滑（`ml-savitzky-golay`）在 Web Worker 中计算，仅作视觉辅助，可开关显示；面积默认基于原始曲线。
- **手工积分复核**：图上拾取或数值输入峰起点/终点，直线基线以两端点偏移调整；系统用**梯形法**计算毛面积、基线面积、净面积，并显示**调整前（端点连线默认基线）与调整后的差值及相对差**。
- **简单基线建议**：`ml-matrix` 最小二乘在 Worker 中对峰外区间做直线拟合，一键换算为端点偏移采用。
- **撤销 / 重做**：所有方法编辑（区间、基线、平滑参数）均可撤销（Ctrl+Z）与重做（Ctrl+Y / Ctrl+Shift+Z）；重新导入后历史清空、可重新计算。
- **持久化**：原始曲线与方法（区间、基线、平滑参数）存入 IndexedDB，刷新后自动恢复上次会话。
- **面积核对**：内置解析面积已知的高斯峰（纯峰、叠加线性基线）与一条可见三峰样例曲线，列出已知面积、计算面积、差值与相对差的全部数值，并可“载入查看”曲线手工复核。工具只呈现数值，不给出固定阈值的自动通过/失败结论。

## 技术栈

Vue 3 + TypeScript（组合式编辑）、Plotly.js（绘图，预构建文件经 `public/vendor` 加载）、
ml-savitzky-golay 与 ml-matrix（Web Worker 内计算）、idb（IndexedDB）、Vite、Vitest。

## 使用

```bash
npm install
npm run dev        # 开发
npm test           # 单元测试（积分/CSV/合成峰核对/Worker 算法）
npm run build      # 类型检查 + 生产构建（输出 dist/）
npm run preview    # 预览构建产物
```

`samples/demo.csv` 为含三个高斯峰与漂移基线的示例数据，可直接导入试用；
也可在界面中点击“载入示例曲线”。

## 核对方法说明

- 用例 A/B：无噪合成高斯峰（A=1000, μ=50, σ=2，区间 μ±6σ），已知面积 = A·σ·√(2π)·erf(6/√2)；
  参考基线列的相对差应在 1e-6 量级以下（梯形离散 + 截断修正后）。
- 用例 C：可见三峰样例（含确定性小幅噪声与弯曲基线），已知面积为三个高斯分量解析面积之和；
  “参考基线”列反映噪声涨落，“端点连线”列还包含直线基线对弯曲基线的模型误差——两者并列展示，供人工判断。

升级 Plotly：`npm install -D plotly.js-dist-min@<版本> && npm run vendor:plotly`。
