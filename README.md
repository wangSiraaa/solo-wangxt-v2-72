# 本地色谱曲线复核工具

纯本地运行的色谱曲线复核（积分区间核对）工具，**没有任何服务端**。技师导入「时间—响应值」CSV 后，
可查看原始曲线、可选叠加 Savitzky–Golay 平滑辅助曲线，手工设置峰的起止点与直线基线，
系统用**梯形法**对**原始数据**计算面积，并显示当前基线与调整前后的差异。

## 技术栈

- **Vue 3 + TypeScript**：组件与编辑逻辑（`<script setup>`、组合式函数）
- **Plotly.js**（`plotly.js-dist-min`）：曲线、基线、净面积区域绘图，支持图上点击拾取起止点
- **Web Worker**：`ml-savitzky-golay`（可选平滑）与 `ml-matrix`（最小二乘简单基线估算）在后台线程运行，不阻塞绘图
- **IndexedDB**：本地保存「原始曲线 + 复核方法（区间/基线/平滑参数）」，可重新打开、删除
- 全部数据与计算均在本机浏览器完成

## 快速开始

```bash
npm install
npm run dev        # 开发服务器
```

构建生产产物（内存充足的标准环境）：

```bash
npm run build      # vue-tsc 类型检查 + Vite/Rollup 打包 -> dist/
npm run preview
```

低内存环境备用构建（esbuild 直连，内存占用显著更低，产物在 `dist-esbuild/`，功能等价）：

```bash
npm run build:lite
# 然后用任意静态服务器，例如：
npx serve dist-esbuild   # 或 python3 -m http.server -d dist-esbuild
```

> 说明：在本仓库构建时，宿主机可用内存仅约 1.5GB，Rollup 的 `rendering chunks` 阶段会被系统
> SIGKILL（与代码无关，类型检查 `vue-tsc` 全程通过）。因此提供了 `build:lite` 备用管线。

## 数值核对（重要）

面积正确性不靠固定阈值的自动结论，而是运行时把梯形法结果与**已知解析面积的合成峰**逐项对照：

```bash
npm run check:math
```

核对内容（见 `src/lib/synthetic.ts`、`scripts/check.ts`）：

1. **单高斯峰**（零基线）：梯形面积对照解析解
   `A·σ·√(2π)·erf(k/√2)`，区间 μ±4σ、801 点，相对差异 ~10⁻⁹。
2. **重叠双峰**：解析面积为两峰之和，对照梯形结果。
3. **高斯峰 + 线性漂移**（`y=0.4+0.02t`）：直线基线取真实漂移端点，校正后净面积对照高斯解析面积；
   同时展示若误用零基线，毛面积会明显偏大（包含漂移梯形面积）。
4. **梯形法 O(h²) 二阶收敛**：网格 n=101→401→1601，误差阶比实测 ~16（h 减半误差降 4 倍，跨两级=16）。
5. **区间端点不落在采样点上**：起止点在采样点之间时用线性插值，结果仍与解析面积吻合。
6. **直线基线恒等核对**：`y=1+2t` 与基线重合时净面积严格为 0、毛面积与基线下方均为 110。
7. **可见曲线样例**：一条含 5 个高斯峰 + 漂移 + 确定性噪声的 901 点曲线，确定性可复现，供手工复核。

界面底部「面积核对」面板在页面加载时即运行这些合成峰核对，展示梯形值、解析值、相对差异，
以及截断宽度 k=3…6 的收敛表；技师自行判读，程序不输出「合格/不合格」之类的阈值判定。

## 操作说明

1. 左上角「导入 CSV」：两列数值（时间、响应值），支持逗号/分号/制表符/空白分隔，
   允许 `#`、`%`、`//` 注释行与单行表头；时间必须严格递增。
2. 左侧手工设置**起点/终点**（可输入数值，或点「图上拾取」后在曲线上点击）。
3. 选择**直线基线**（输入两端响应 y₀/y₁，可用「贴曲线」吸附到端点原始响应；
   「Worker 最小二乘估算」用区间两端若干点做最小二乘，仅填入可再改的建议值）或**零基线**。
4. 勾选「显示 SG 平滑曲线」可叠加橙色虚线辅助观察峰形——**平滑仅用于观察，绝不参与面积计算**。
5. 右侧显示毛面积、基线下方面积、净面积，以及「当前 vs 调整前」的逐项差异表。
6. **撤销/重做**（按钮或 Ctrl+Z / Ctrl+Shift+Z）覆盖所有区间、基线、平滑设置改动。
7. 「保存方法 + 原始曲线」写入 IndexedDB；刷新后自动恢复上次打开的曲线；可随时重新导入同一条曲线重复计算。

## 设计要点

- **原始数据始终可查看且不被修改**：平滑曲线独立保存，积分函数 `integrate()` 只读取原始 `points`。
- **边界插值**：起止点落在采样点之间时，原始曲线按相邻点线性插值，基线按直线取值，保证合成峰核对一致。
- **面积可重复**：所有设置与曲线点确定性可复现；重新导入、撤销重做后均可重复计算。
